# 올라운드 관리자 운영 콘솔

이 문서는 `docs/design/pureform-sports-system.md`를 관리자 화면에 적용하는 짧은
surface direction이다. 전역 앱 디자인을 대체하지 않으며, 운영 도구의 정보 구조만
구체화한다.

## 목적과 분위기

- 관리자가 검수 대기, 공개 대회, 수집 상태와 운영 도구를 몇 초 안에 찾는다.
- `Operate` 모드로 설계한다. 차갑고 단정하며, 장식보다 정보 밀도와 반복 작업의
  예측 가능성을 우선한다.
- getdesign.md의 Linear 분석에서 정밀한 위계와 단일 강조색 원칙만 참고한다.
  색과 브랜드 표현은 올라운드 Pureform Sports를 그대로 따른다.

## 시각 규칙

- 색: `ColorScheme`과 `app/lib/theme/` 토큰만 사용한다. 코발트는 현재 위치와
  이동 행동에만 쓴다.
- 글자: Pretendard 한 계열을 유지한다. 화면 제목, 섹션 제목, 작업명, 보조 설명의
  네 단계만 사용한다.
- 간격: `AppSpacing`, 크기와 모서리는 `AppSizes`·`AppRadius`를 사용한다.
- 표면: 한 운영 영역은 하나의 평면 패널로 묶고 1px 구분선으로 작업을 나눈다.
  중첩 카드, 장식 그림자, 그라데이션은 사용하지 않는다.
- 아이콘: 프로젝트의 Material Rounded 계열을 유지하고 색만으로 상태를 전달하지
  않는다.

## 정보 구조와 동작

- 운영 홈의 첫 영역은 대회 처리 순서를 그대로 보여준다:
  `제보·Draft 검수 → 요강 정형화 검수 → 공개 대회 관리 → 수집 상태`.
- 지식베이스, 협회·랭킹, 클럽·커뮤니티는 별도 운영 영역으로 묶고 기존 화면으로
  이동시킨다.
- 안전하게 조회한 값이 없으면 건수나 성공 상태를 추정하지 않는다. 운영 홈은
  정직한 설명과 바로가기를 제공하고, 실제 상태는 각 관리 화면에서 확인한다.
- `/admin` 서버·DB 권한 경계는 유지한다. 화면 구조는 권한 판정을 대신하지 않는다.

## 반응형·접근성

- 데스크톱의 높은 정보 밀도를 기본으로 하되 좁은 창에서는 설명과 행동이 세로로
  재배치되어 가로 스크롤이 생기지 않아야 한다.
- 모든 이동 행과 버튼은 최소 48px 터치 영역, 키보드 포커스, 명확한 한국어
  레이블을 제공한다.
- 라이트·다크 테마와 텍스트 130%에서 같은 읽기 순서를 유지한다.
