# 2026-08-20 회의 수정사항 — 업무분담과 결정사항

## 목적

회의에서 나온 수정사항을 한 곳에 모으고, 백과장이 큰 방향을 결정한 뒤 시리가 화면 구현을 이어받을 수 있게 한다.

이 문서는 구현 PR이 아니라 **업무분담·정책 확인용 문서**다. 백과장은 이 PR에 결정사항·담당자·우선순위를 코멘트로 남긴다.

## 현재까지 확정된 방향

- 휴대폰 인증은 실명인증이 아니라 SMS를 통한 번호 점유 확인이다.
- 신규 가입 시 휴대폰 번호를 받고 인증번호를 확인한다.
- 로그인 자체를 제한하거나 로그인 때마다 다시 인증하는 기능은 현재 범위에서 제외한다.
- 회원 찾기는 휴대폰 인증 후 가입 이메일과 로그인 방식(Google/이메일)을 확인하는 흐름으로 만든다.
- 랭킹 기록은 최고 순위·최고 포인트·최고 대회 기록을 모두 다룬다.
- 검색 이력은 서버가 아니라 현재 기기에만 저장한다.
- 도메인 연결은 도메인 주소를 정한 뒤 별도로 진행한다.
- 이미지 번들링과 이미지 사용 규정은 아직 결정하지 않는다.
- “리액트 라우트” 관련 메모는 이번 작업에서 보류한다.

## 업무분담 초안

### 백과장 — 큰 방향·제품 결정·QA 기준

- 신규 가입 화면에서 휴대폰 인증을 받는 단계 결정
- 기존 가입자 중 휴대폰 번호가 없는 계정의 처리 방식 결정
- 회원 찾기 화면의 흐름과 문구 결정
- Google 계정과 이메일 계정 표시 방식 결정
- 랭킹 화면의 구성 결정
  - 현재 순위
  - 역대 최고 순위
  - 역대 최고 포인트
  - 최고 성적 대회
  - 월별·연별 순위 및 포인트 변화
- 기기별 해상도·스크롤·줄바꿈·모달·뒤로가기 QA 기준 결정
- 이미지 규정 초안 결정
  - 앱 번들 이미지와 외부 이미지의 사용 기준
  - 출처·권리 확인
  - 권장 크기·비율·용량
  - 압축·대체 이미지 기준

### 시리 — 백과장 결정 후 Flutter 구현·검증

- 회원가입 휴대폰 번호·인증번호 입력 화면
- 인증 성공·실패·만료·재전송·횟수 초과 상태
- 회원 찾기 화면과 Google/이메일 계정 안내
- 랭킹 최고 기록 및 월별·연별 변화 화면
- 전역 종목 선택 상태와 화면 이동 시 유지 여부
- 대회·랭킹 이동 시 하단 탭 상태 수정
- 스크롤·줄바꿈·해상도·모달·뒤로가기 문제 수정
- 현재 기기 로컬 검색 기록 UI
- Flutter 위젯·화면 테스트 및 실기기 QA

시리는 백엔드 인증 정책, DB 마이그레이션, 공용 enum, 도메인 연결을 임의로 변경하지 않는다. 필요한 API 형식은 드론과 먼저 맞춘다.

### 나/드론 — 인증·데이터·백엔드

- SMS OTP 발송·검증 API와 번호별 중복 방지
- 신규 가입 시 휴대폰 인증 연결
- 이메일 정규화·중복·유니크 처리
- Google/이메일 로그인 방식 구분
- 회원 찾기 API
- 탈퇴 시 개인정보 삭제·익명화와 최소 탈퇴 이력
- 랭킹 snapshot 및 최고 기록 계산 API
- 검색 기록의 기기 로컬 저장을 위한 API 변경 여부 확인
- 도메인 확정 후 약관·관리자 주소 반영
