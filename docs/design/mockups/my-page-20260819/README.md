# MY 페이지 단순화 시안 (2026-08-19)

현재 MY 화면의 기능을 유지하면서, 한 화면에서 보이는 메뉴 수와 정보 위계를 줄이는 방향으로 만든 비교 시안이다.

## 시안

1. `01-core-three.png` — 핵심 3개: 관심·내 클럽·내 기록만 바로 노출
2. `02-activity-settings-tabs.png` — 활동/설정 탭: 콘텐츠와 설정을 완전히 분리
3. `03-accordion-groups.png` — 접이식 그룹: 전체 기능은 유지하되 한 그룹만 펼침
4. `04-profile-activity.png` — 프로필 중심: 완성도와 최근 활동을 우선 표시
5. `05-search-hub.png` — 검색형 메뉴: 자주 찾는 4개와 전체 메뉴 검색

## 공통 기준

- Pureform Sports 색상과 평면 목록 스타일
- 390px 모바일 본문 기준
- 하단 내비게이션 `대회 · 클럽 · 볼보이 · MY`
- 낮은 빈도의 계정·화면·약관 메뉴는 2차 화면으로 이동
- 그라데이션, 장식용 그림자, 중첩 카드 제외

## 추천

구현 우선안은 2번이다. 활동 정보와 설정을 분리해 첫 화면 밀도를 크게 낮추면서도, 검색이나 아코디언을 학습하지 않아도 된다. 더 과감하게 단순화하려면 1번이 적합하다.
